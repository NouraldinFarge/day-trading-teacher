Day-Trading Teacher Portable

Educational software only. This application does not provide investment advice, live buy/sell signals, order placement, or promises of trading outcomes.

1. Extract this entire folder to any writable location.
2. Run launch-portable.bat or Day-Trading Teacher.exe.
3. Your application data stays in the adjacent data folder. Logs, cache, and configuration folders are also kept beside the executable.

The interface is bundled into the executable. No localhost development server or internet connection is required to open the app. Optional automatic chart downloads require internet access and credentials for the market-data provider you explicitly choose.

The application includes the reviewed Evidence to Execution v7 learner curriculum in Lessons. Open practice cases, a glossary, accessible examples, and reusable worksheets are also available under assets\curriculum-v7. Secure facilitator assessment packets, outcome classes, scoring keys, and reveal material are intentionally not included. App completion is practice evidence, not live-trading certification.

No installation, administrator access, registry changes, service, driver, or uninstaller is required.

Windows limitation: this application uses Microsoft WebView2, which is included with current supported Windows installations. If WebView2 is missing on an older or heavily managed computer, Windows must provide it before the app can run.
