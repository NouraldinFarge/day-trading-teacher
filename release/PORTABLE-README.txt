Day-Trading Teacher Portable

Educational software only. This application does not provide investment advice, live buy/sell signals, order placement, or promises of trading outcomes.

1. Extract this entire folder to any writable location.
2. Run launch-portable.bat or Day-Trading Teacher.exe.
3. Your application data stays in the adjacent data folder. A compact state core and coordinated collection files keep large chart, trade, paper-session, curriculum, and learning records recoverable without one oversized save. Logs, cache, and configuration folders are also kept beside the executable.

Launching Day-Trading Teacher.exe opens the graphical app without a terminal window. The batch file is a readable fallback that reports launch errors.

The interface is bundled into the executable. No localhost development server or internet connection is required to open the app. Optional automatic chart downloads require internet access and credentials for the market-data provider you explicitly choose.

The application includes the reviewed Evidence to Execution v7 learner curriculum in Lessons. Open practice cases, a glossary, accessible examples, and reusable worksheets are also available under assets\curriculum-v7. Secure facilitator assessment packets, outcome classes, scoring keys, and reveal material are intentionally not included. App completion is practice evidence, not live-trading certification.

Custom lessons are JSON files authored outside the app and imported only after local validation, preview, and explicit approval. The Journal can also create a redacted Trading Records package for an external AI and validate returned journal drafts. Chosen drafts create a local Trade Lessons workspace that works newest-to-oldest, preserves every original lesson, separates hindsight from contemporaneous evidence, and links repeated process patterns. Reviewing one of these audits records reflection only; it does not claim mastery. The app has no embedded AI and never sends lessons, records, or journals to ChatGPT automatically.

Fidelity support is deliberately read-only: the app can detect a root-level Trading_Records folder beside this portable build, recursively scan supported dated Orders and chart CSVs, treat Buy amounts as dollars invested, reconstruct completed positions, pair same-day one-minute charts, detect an installed Trader+ application, and prepare a ticket checklist. While the Journal is open, quick metadata probes avoid rereading unchanged CSVs every minute. You control folder selection and every external-AI file handoff. It never requests Fidelity credentials, reads an account directly, watches the screen, uploads records automatically, or places an order.

Before replacing or moving an active portable folder, copy its data and config folders to a safe location. Provider credentials are protected separately in Windows Credential Manager for the current Windows user and are intentionally excluded from app-state exports and portable ZIPs. Moving the folder to another Windows user requires entering those provider credentials again. Older plaintext provider files are removed after a successful protected-store migration.

No installation, administrator access, registry changes, service, driver, or uninstaller is required.

Windows limitation: this application uses Microsoft WebView2, which is included with current supported Windows installations. If WebView2 is missing on an older or heavily managed computer, Windows must provide it before the app can run.
