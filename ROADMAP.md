# Roadmap

Day-Trading Teacher prioritizes measurable learning and review quality over engagement, trade frequency, or simulated profit.

## Near term

- Expand deterministic regression coverage for imports, calculations, and recovery.
- Publish verified portable releases with checksums and concise release notes.
- Improve accessibility and keyboard-first chart/review workflows.
- Strengthen the evidence bridge between planning, replay, journal records, and remediation.

## Later

- Add more versioned curricula and open-practice cases with explicit provenance.
- Improve redacted export options for coaching and self-review.
- Evaluate additional historical-data providers only with documented, user-controlled credentials and strict provider identity.

## Non-goals

- Live buy/sell signals, investment advice, return promises, or execution coaching based on current market conditions.
- Brokerage credential storage, account scraping, or automatic order entry.
- Hidden AI calls, cloud accounts, or mandatory telemetry.
