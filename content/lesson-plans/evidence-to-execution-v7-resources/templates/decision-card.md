# Progressive decision card

## Basic six
1. Evidence timestamp
2. Setup or no-setup statement
3. Objective trigger
4. Invalidation
5. Maximum planned loss
6. Cancellation conditions

## Add only when applicable
- Quantity and binding constraint
- Spread or liquidity limit
- Order behavior and accepted failure
- Partial-fill response
- Gap, halt, reconnect, or borrow response
- Exit architecture
- Session stop status
