# Evidence to Execution v7 — learner resources

These files support the bundled, simulation-only `Evidence to Execution v7` lesson plan.

The application embeds the reviewed learner plan and offers it through Lessons. This companion folder provides the open practice case bank, glossary, accessible visual examples, and reusable worksheets for work outside the lesson reader.

Security boundary:

- Scored assessment, remediation, retention, and capstone packets are not included.
- Facilitator outcome classes, accepted decisions, scoring keys, and reveal material are not included.
- An opened or exposed scored form must not be reused for mastery.
- App completion is deliberate-practice evidence, not live-trading certification or proof of profitability.

The plan is limited to simulation-only U.S.-listed stocks and ETFs. It does not provide live trade signals, personalized investment recommendations, or automated orders.
