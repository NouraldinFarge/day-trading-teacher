# Support

Day-Trading Teacher is an educational, local-first portfolio application. It does not connect to a brokerage, provide live signals, offer investment advice, or place orders.

## Before opening an issue

1. Confirm the version shown in the app’s Settings page or the `VERSION` file beside the portable executable.
2. Reproduce the problem with the latest verified [GitHub release](https://github.com/NouraldinFarge/day-trading-teacher/releases/latest) when practical.
3. Review the [documentation hub](docs/README.md), [privacy model](PRIVACY.md), and [security policy](SECURITY.md).
4. Remove account numbers, names, order identifiers, file paths, screenshots of private records, and other personal or financial data from anything you share.

## Where to ask

- Use the [bug-report form](https://github.com/NouraldinFarge/day-trading-teacher/issues/new?template=bug_report.yml) for reproducible product defects.
- Use the [documentation form](https://github.com/NouraldinFarge/day-trading-teacher/issues/new?template=documentation.yml) for unclear or inaccurate public documentation.
- Follow the [security policy](SECURITY.md) for suspected vulnerabilities; do not publish sensitive security details in a public issue.

The repository does not provide individual financial or trading support. Product questions should first use the documentation hub; open an issue only when the documentation or product behavior is reproducibly unclear.

## Include in a useful report

- App version and Windows version
- Portable or development build
- The workspace involved, such as Lessons, Chart Replay, Journal, or Trade Lessons
- Exact steps, expected behavior, and observed behavior
- A minimal synthetic example when data is needed to reproduce the problem
- Relevant error text with private data redacted

Support is best-effort and does not include financial, trading, tax, legal, or account-specific advice. Never share brokerage credentials or upload unredacted trade-history files.
